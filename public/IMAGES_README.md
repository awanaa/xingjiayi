三、首页 Section 3 — Process（流程 8张）

文档推荐流程：Engineering → Sampling → Printing → Binding → Hand Assembly → Quality Assurance → Packaging → Global Delivery
统一风格：纪实工作场景，非摆拍，偏工业风。

9. process-engineering.jpg

步骤：01 Engineering — 结构评估与可制造性分析
场景：设计师在电脑前操作 3D 纸艺结构设计软件（CAD/AI）
桌面：桌上放一个结构打样白胚（未印刷的纯白模型）
屏幕：显示展开图/刀模线框
景别：中景——电脑 + 人侧影 + 白胚

10. process-sampling.jpg

步骤：02 Sampling — 白样/彩样/功能样
场景：打样机工作台，刚切出的样品平铺桌面
细节：桌面有设计稿、半成品、修改批注
焦点：模切边缘的平整度

11. process-printing.jpg

步骤：03 Printing — 色彩管理与印刷
场景：海德堡印刷机运作中，纸张经过印刷单元
细节：墨槽/墨辊近景，彩色印刷品从出料口输出
体现：高精度、色彩管理
人物：操作工在色彩对色灯旁检查

12. process-binding.jpg

步骤：04 Binding — 装订与裱合
场景：自动装订线运作，书本经过骑马订/胶装工位，或异形加工/自动折页机工作场景
体现：自动化、精密成型

13. process-hand-assembly.jpg

步骤：05 Hand Assembly — 手工装配
场景：女工坐在工作台前手工组装立体书结构、粘贴部件
景别：近景——手指在粘合纸艺部件（持胶水/贴双面胶）
光线：柔和，体现手工的温度感

14. process-quality.jpg

步骤：06 Quality Assurance — 来料、过程、成品及功能测试
场景：QC 工作台，操作员在测试/检查
细节：拉力计/对色灯箱/检测记录表在同画面
体现：严谨、标准化

15. process-packaging.jpg

步骤：07 Packaging — 零售包装与运输保护
场景：自动包装线 / 书本进入热缩包装 / 装箱过程
亮点：可展示减塑包装方案（纸卡/纸绳替代塑料）

16. process-delivery.jpg

步骤：08 Global Delivery — 出货与物流
场景：立体货架 + 码垛好的成品托盘
细节：叉车装货或仓库全景
亮点：纸箱上有出口目的地标签（体现全球交付）


四、首页 Section 4 — Quality（质量 6项）

17. quality-color-management.jpg

模块：Color Management — 色彩管理
场景：操作员在标准光源灯箱下对比色稿和印刷品
焦点：色谱/色票/印刷样并排放置
体现：从打样到量产的色彩一致性

18. quality-incoming.jpg

模块：Incoming Inspection — 来料检验
场景：进厂纸卷/油墨的检测环节
细节：工人用仪器测纸张克重/含水率/挺度
焦点：检测仪器屏幕数值 + 材料样本

19. quality-inprocess.jpg

模块：In-process Control — 过程巡检
场景：印刷/装订线旁的在线检测或巡检
焦点：操作员在触摸屏查看检测数据或查看正在产出的印品

20. quality-functional-test.jpg

模块：Functional Testing — 功能测试
场景：测试员测试机关书的推拉滑轨顺畅度 / 磁力吸附力，或跌落测试现场
焦点：测力计数值 + 产品受力状态

21. quality-final-inspection.jpg

模块：Final Inspection — 成品检验（AQL）
场景：质检员翻开成品检查每一页的开合是否顺畅
桌面：已检合格品 + 不合格品标记件并排放
体现：出厂前的最后把关

22. quality-traceability.jpg

模块：Traceability — 追溯系统
场景：操作员扫描成品上的追溯码
屏幕：显示批次追溯系统界面
体现：批量→物料→检验→异常处理的完整追溯链

文档原文 6 条，一一对应：

23. sustainable-fsc.jpg

内容：FSC认证或可追溯纸张
场景：一卷或一叠带 FSC 标签的纸张
焦点：FSC 标签/印章清晰可见

24. sustainable-recycled.jpg

内容：再生纸、轻量化和材料减量方案
构图：左右对比——左侧原生白纸，右侧再生纸带纤维质感，或同一本书用薄型轻量纸 vs 传统厚纸的厚度对比

25. sustainable-ink.jpg

内容：大豆油墨、低迁移油墨
场景：大豆油墨桶，油墨表面光泽，旁边放一粒大豆/玉米暗示植物基来源，或印刷色卡叠在植物图案上

26. sustainable-packaging.jpg

内容：减塑包装、可回收结构及运输包装优化
构图：同一产品的包装对比——旧版塑料热缩膜 vs 新版纸卡/纸绳
标签：可在旁边标注"塑料减少 XX%"（数字需真实）

27. sustainable-waste.jpg

内容：排版、拼版和生产计划中的减废措施
场景：废纸边角料打包成捆准备回收，或模切后剩余的镂空纸骨架
体现：废料也是资源

28. sustainable-energy.jpg

内容：能源、废弃物或碳管理的真实改进项目
场景：车间顶部的采光带 / 太阳能光伏板，或能耗监控屏幕（实时数据），或改造后的 LED 照明 vs 旧日光灯对比




30. global-delivery-scene.jpg

场景：全球交付实景
构图：集装箱装货现场 / 发货区，或印有不同国家地址的发货单/出口箱单特写
体现：服务海外市场
